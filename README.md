# Autonomous Agent Pipeline

The Opportunity Scout is an autonomous agent I built on Relevance AI. It runs once a week, looks for funding and prize opportunities for builders, and sends the results to me by email.

## What it does
- Searches the web for grant, prize, and partner-program listings.
- Checks each listing against its official page.
- Keeps only opportunities that pay cash, cost nothing to claim, and are still open.
- Sends a digest with the deadline, source link, and amount.

## How it runs
1. Search for funding listings.
2. Check each listing against its official page.
3. Email a digest.

## What it doesn't do
- It doesn't apply to anything.
- It doesn't contact sponsors or submit forms.
- It doesn't spend money or pay for access.
